# Jun Xu

Computer Science student at the National University of Singapore interested in backend engineering, systems, developer tools, and open-source software.

I enjoy building practical applications, working across the full stack, and investigating problems that cross software and hardware boundaries.

## Technologies

- **Languages:** Java, Python, TypeScript, JavaScript
- **Backend:** FastAPI, REST APIs, PostgreSQL
- **Frontend:** React, Next.js, Tailwind CSS
- **Tools and systems:** Git, Docker, GitHub Actions, Linux, Android, OpenWrt

## Selected projects

### [ParkCastSG](https://github.com/gekjunxu/parkcastsg)

A Singapore carpark search and pricing application built with React and FastAPI. It integrates OneMap, data.gov.sg, and LTA DataMall to provide nearby carpark search, live availability, pricing information, weather, and navigation links.

### [OpenEUICC](https://github.com/gekjunxu/openeuicc)

Open-source Android eSIM management software. I have worked on debugging and understanding Android OMAPI, eSIM channel lifecycle, and reconnection behaviour.

### [RepoSense](https://github.com/gekjunxu/RepoSense)

An open-source contribution analysis tool for Git repositories that visualises code contributions and commit history.

### [Prof-iler](https://github.com/gekjunxu/tp)

A Java desktop application for managing student research records, developed as a team software-engineering project.

### [Hackintosh GA-B85-HD3 OpenCore](https://github.com/gekjunxu/Hackintosh-GA-B85-HD3-OpenCore)

An OpenCore configuration for running macOS on a Gigabyte GA-B85-HD3 system, reflecting my interest in operating systems, hardware, and troubleshooting.
