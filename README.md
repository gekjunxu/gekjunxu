## Selected projects and contributions

### [Canvas Sync](https://github.com/gekjunxu/canvas-sync)

An existing cross-platform Qt tool that keeps local folders synchronised with online folders on Canvas. I recently repaired and updated the tool for use during my current semester.

### [ParkCastSG](https://github.com/gekjunxu/parkcastsg)

A Singapore carpark search and pricing application built with React and FastAPI. It was originally developed as a group project, which I continued and expanded independently in my free time. It integrates OneMap, data.gov.sg, and LTA DataMall to provide carpark search, availability, pricing, weather, and navigation links.

### [RepoSense](https://github.com/gekjunxu/RepoSense)

During CP3108A and the NUS OSS programme, I contributed to RepoSense, an open-source contribution analysis tool for Git repositories.

My work included:

- Implementing a responsive top/bottom split view for narrow and mobile portrait layouts
- Adding frontend tests for chart blurbs
- Fixing a Windows Gradle build issue involving `npm.cmd` — [merged upstream](https://github.com/reposense/RepoSense/pull/2484)
- Fixing a date-format issue in the user guide
- Investigating iOS Safari crashes caused by high memory usage in large reports

See my [contribution report](https://github.com/gekjunxu/RepoSense/blob/master/README.md) and [RepoSense contributions](https://github.com/gekjunxu/RepoSense/pulls?q=is%3Apr+author%3Agekjunxu).
